1. Product Identification & Positioning

Project ORION is a proprietary multi-tenant web application and REST API runtime designed for quantitative researchers, algorithmic prop desks, and institutional software evaluators.

  • Core Value: End-to-end quantitative pipeline taking strategies from mathematical formulation through walk-forward efficiency scoring to paper incubation.
  • Mathematical Hygiene: Validates algorithmic robustness via qualified LeakageGuard temporal checks and programmatic quality gate hurdles.
  • Asset Scope: Proposed transferable software and intellectual property asset scope; clean corporate separation with zero customer liability.
2. Modern Technology Stack
  • Backend Engine: Python 3.11+, FastAPI (ASGI), Pydantic v2 schemas, SQLAlchemy 2.0 Async ORM (24 routers).
  • Frontend SPA: React 18, Vite, TypeScript, Tailwind CSS, TanStack Query, Lucide Icons (20 routes).
  • Database: PostgreSQL 16 with 15 linear Alembic migrations managing 29 relational tables.
  • Cache & Broker: Redis 7 with graceful in-memory degraded fallback for sessions and rate-limits.
  • PaaS Infrastructure: Render PaaS blueprint (~$14/mo baseline configuration hosting estimate).
3. Ten Implemented Core Capabilities
  • 1. Deterministic Backtesting: Sequential chronological bar traversal with trade-by-trade analytics and cent-level reproducibility.
  • 2. Temporal Leakage Protection: LeakageGuard enforces timestamp monotonicity; prevents indicator look-ahead bias.
  • 3. Multi-Parameter Optimization: Grid search exploring parameter surfaces with metric-based ranking (Sharpe/Sortino).
  • 4. Walk-Forward Analysis (WFA): Rolling In-Sample & Out-Of-Sample slices computing Walk-Forward Efficiency (WFE).
  • 5. Automated Quality Gates: Programmatic hurdles (WFE ≥ 0.50, DD ≤ 15%, parameter stability) governing promotion.
  • 6. Realistic Paper Execution: PaperExecutionAdapter models spread, adverse slippage, and position netting ($0 live risk).
  • 7. Pre-Trade Risk Engine: Dynamic evaluation of margin, leverage ceilings (1:100 default), and drawdown limits.
  • 8. Multi-Tenancy & RBAC: 7 organizational roles governing 41 permissions; isolated database queries via TenantContext.
  • 9. Structured Audit Trail: Immutable AuditLogModel logging acting user IDs, timestamps, and JSON metadata.
  • 10. Declarative Cloud Blueprint: Single-command 4-tier PaaS deployment via render.yaml with preDeploy migrations.
