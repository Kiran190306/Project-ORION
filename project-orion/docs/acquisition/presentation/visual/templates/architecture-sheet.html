2. Major Data Flow & Interface Sequences
Flow A: Order Submission & Simulated Execution
Trader (Client) ──> POST /api/v1/orders/ (CreateOrderRequest + JWT)
FastAPI Router ──> Validates JWT & resolves TenantContext
OrderService ──> Resolves active paper account & dispatches to EntitlementService
EntitlementService ──> Verifies daily order quota for subscription tier (e.g. 2,500/day)
RiskService ──> Evaluates simulated margin, leverage cap (1:100 default) & account drawdown
PaperExecutionAdapter ──> Models spread, adverse slippage & position netting (is_paper=True)
SQLAlchemy Session ──> Persists OrderModel, FillModel, PositionModel & writes ORDER_CREATE audit log
FastAPI Delivery ──> HTTP 201 Created (OrderResponse with is_paper=True, $0.00 capital at risk)
Flow B: Deterministic Backtesting with LeakageGuard
Quant User (Browser) ──> POST /api/v1/research/experiments (ExperimentRunRequest)
ResearchService ──> Resolves StrategyRegistry class & loads historical candles from provider
DeterministicBacktestEngine ──> Sequential chronological bar traversal (t[0] ──> t[N])
LeakageGuard ──> validate_slice() verifies temporal monotonicity: timestamp[i] <= timestamp[i+1]
PerformanceCalculator ──> Computes Sharpe, Sortino, Max Drawdown, Win Rate & Profit Factor
FastAPI Delivery ──> HTTP 201 Created (ExperimentSummaryResponse with cent-level identical curves)
Flow C: Walk-Forward Analysis & Robustness Scoring
Quant User (Browser) ──> POST /api/v1/optimization/walk-forward (WalkForwardRunRequest)
OptimizationService ──> Slices dataset into rolling In-Sample (IS) & Out-Of-Sample (OOS) windows
WalkForwardEngine ──> Optimizes on IS; evaluates best candidate on unseen OOS window
RobustnessAnalyzer ──> Calculates WFE = (Annualized OOS Return / Annualized IS Return)
FastAPI Delivery ──> HTTP 201 Created (Classifies verdict: ROBUST, MODERATE, or OVERFITTED)
3. Multi-Tenant Query Binding

Every database query across accounts, orders, positions, trades, strategies, and deployments executes within a dependency-injected session context enforcing WHERE organization_id = :org_id. Cross-tenant data leakage is mitigated at the ORM layer.

4. Precision Math & Safety Invariants

All balances, lots, pip values, execution prices, and P&L measurements strictly use Python Decimal arithmetic. The execution layer contains zero code pathways to live brokerage clearing APIs. Live financial capital at risk is strictly $0.00.
