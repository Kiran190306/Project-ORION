# Shared

This directory contains shared types, constants, enums, and error definitions used across the entire platform.

## Contents

- `constants/` - Shared constants
- `enums/` - Shared enums
- `types/` - Shared types
- `errors/` - Shared error definitions

## Dependencies

No dependencies. This is the core layer.

## Usage

All other modules depend on this directory.

## Ownership
- Platform Team (primary)
- All teams (consumers)
