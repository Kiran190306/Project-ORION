# SDK

This directory contains client SDKs for external consumers to interact with Project ORION.

## SDKs

- `python/` - Python SDK
- `javascript/` - JavaScript/TypeScript SDK
- `go/` - Go SDK

## Dependencies

All SDKs depend on:
- `api/` - API definitions
- `shared/` - Shared types and constants

## Ownership
- Platform Team (primary)
- API Team (API definitions)
